# 🐭 Mushak's Mission

A pixel-art adventure game inspired by the Ganesh Chaturthi festival.

## 🎮 About the Game

Mushak's Mission is a 2D pixel-art adventure game where you play as Mushak, Lord Ganesha's mouse companion.

Your goal is to collect the ingredients required for the pooja while exploring the garden and house, avoiding obstacles and escaping from enemies.

## 🕹️ Gameplay

- Explore the garden and house
- Collect required pooja ingredients
- Complete missions in order
- Avoid the chasing cat
- Manage your 3-heart health system
- Enter the house to continue the adventure
- Complete all available missions

## 🎯 Controls

- **Arrow Keys / WASD** — Move Mushak
- **Enter** — Interact / continue dialogue
- **Mouse** — Interact with menu elements

## 🛠️ Built With

- JavaScript
- Phaser
- Vite
- HTML5
- CSS
- Pixel Art
